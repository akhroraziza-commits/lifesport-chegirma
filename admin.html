LIFE SPORT — Boshqaruv

Chegirma foizini o'zgartirish, mahsulotni yashirish va rasmini almashtirish. O'zgarish saytda 1–2 daqiqada ko'rinadi.

Kalitni qanday olish kerak?
  1. GitHub'ga kiring va shu sahifani oching.
  2. Token name: masalan "chegirma admin". Expiration: 1 yil.
  3. Repository access → Only select repositories → lifesport-chegirma.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Generate token tugmasini bosing, chiqqan kalitni nusxalab shu yerga qo'ying.
Kalit faqat shu brauzerda saqlanadi. Uni hech kimga bermang.
